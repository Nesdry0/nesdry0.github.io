# Portafolio de Nesdry Osorio

Portafolio personal y curricular desarrollado como sitio web estático. El proyecto presenta una introducción profesional, información académica y laboral, proyectos, contacto y una demo interactiva de GastroBalance.

## Páginas principales

- index.html: página de inicio y presentación general.
- portafolio.html: proyectos y demos.
- curriculum.html: información curricular.
- contacto.html: formulario de contacto.

## Demo interactiva

- gastro-demo/index.html: demo web de GastroBalance.
- gastro-demo/styles.css: estilos de la demo.
- gastro-demo/app.js: lógica interactiva de la demo.

## Prototipo local

- demo_gastrobalance/app.py: versión local en Python del prototipo.
- demo_gastrobalance/README.md: detalles del prototipo local.

## Archivos generales

- styles.css: estilos del sitio principal.
- script.js: lógica y comportamiento del sitio.
- assets/: recursos visuales del portafolio.
- CNAME: configuración del dominio personalizado.
- portfolio-demo/: demos y recursos adicionales.

## Tecnologías utilizadas

- HTML
- CSS
- JavaScript
- Python

## Descripción

Este proyecto funciona como portafolio personal para mostrar perfil profesional, habilidades, experiencia y proyectos, además de una demo interactiva que presenta una propuesta de solución aplicada.
