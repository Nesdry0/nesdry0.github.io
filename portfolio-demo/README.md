# Guardian App · Demo de portafolio

Demo interactivo autocontenido para presentar la experiencia de Guardian App.

## Abrir

Abre `index.html` directamente en el navegador. No requiere instalación, servidor ni conexión a internet.

## Recorrido sugerido

1. En **Vista estudiante**, selecciona un tipo de situación.
2. Elige una ubicación, agrega un detalle opcional y envía el reporte.
3. Muestra el código de seguimiento `GN-4824`.
4. Cambia a **Vista colegio** para enseñar el panel de convivencia.
5. Prueba el filtro de reportes y los botones de detalle.

Todos los datos del demo son ficticios y la interfaz representa el concepto visual del producto.
